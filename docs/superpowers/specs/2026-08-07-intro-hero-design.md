# 인트로 히어로 — 폰트 순환 A + 터치 반응 도트

2026-08-07. 홈 최상단에 붙는 풀뷰포트 인트로 섹션. 스크롤이 곧 진입이다.

## 결정 경위

- 처음 아이디어는 진입 스플래시 + ENTER 버튼이었으나, 사용자가 스크롤 진입으로 변경.
  → 오버레이·게이트·노출 빈도 정책이 전부 필요 없어졌다. 홈의 첫 섹션일 뿐이다.
- 폰트는 기존 로드분만 쓰는 안 대신 구글폰트 추가를 선택 (더 극적인 대비).
- 도트는 DOM 대신 Canvas (모바일 60fps, DOM 노드 0개 추가).

## 구조

- `src/components/IntroHero.tsx` 하나. `HomePage`의 `<main>` 첫 자식으로 삽입.
- `100svh` 다크 섹션. 배경 `#0d0d0b` (기존 `--black #11110f`보다 한 단계 깊게 —
  종이색 홈과의 대비가 목적).
- 하단 중앙 `↓ SCROLL` 힌트 (기존 eyebrow 타이포 스타일, 밝은 회색).
  탭하면 `scrollIntoView({ behavior: "smooth" })`로 다음 섹션 이동.
- 라우팅 변경 없음, 스토리지 없음.

## A — 폰트 순환

- 대문자 A 한 글자, DOM 텍스트, 크기 ~40vh. `aria-hidden`.
- 순환 풀: Sora(이미 로드) + 구글폰트 4종 신규 —
  Playfair Display(세리프) · UnifrakturMaguntia(블랙레터) ·
  Space Mono(모노) · Archivo Black(그로테스크 헤비).
- `index.html`에서 `text=A` 서브셋 파라미터로 로드 (폰트당 1~2KB).
- `document.fonts.load()`가 확인한 폰트만 풀에 넣는다. 시작은 Sora 하나,
  로드되는 대로 풀이 자란다. FOUT 없음.
- 1초 인터벌, 즉시 스냅 교체 (크로스페이드 없음 — 타이포 스펙시먼의 박자).

## 도트 캔버스

- 풀사이즈 `<canvas>` 1장, `devicePixelRatio` 스케일.
- 격자 간격 ~28px, 기본 도트 rgba(255,255,255,0.06).
- 포인터/터치 반경 ~120px 안 도트가 거리 비례로 밝아짐 (최대 0.5),
  포인터가 떠나면 ~600ms 감쇠.
- rAF 루프는 감쇠가 끝나면 정지. 멀티터치는 첫 포인터만.
- 물리·파티클 없음. 단순 거리 계산 + 감쇠뿐.

## 접근성 · 성능

- `prefers-reduced-motion`: 폰트 순환 정지(Sora 고정), 도트는 정적 그리드.
- IntersectionObserver: 히어로가 뷰포트 밖이면 인터벌·rAF 정지.
- 스크린리더: 섹션에 라벨, A는 장식이므로 숨김.

## 검증

- 폰트 풀 로직(로드 완료된 것만 순환에 들어감) 단위 테스트 1개.
- 나머지는 devtools 모바일 뷰포트(390px) 스크린샷으로 확인.
