# 픽셀 우로보로스 마스코트

2026-08-10. 사이트를 가끔 기어다니는 픽셀 뱀. 쉴 때 몸을 말아 꼬리를 무는
우로보로스가 된다 — 우로보로스는 정체성이 아니라 "쉬는 자세"다.

## 형태

- 스네이크 게임 방식: 8px 논리 셀 격자, 머리가 한 셀씩 전진하고 몸이 따라온다.
  셀당 7px 사각형(1px 틈) — 픽셀 그리드 질감.
- 길이 ~14세그먼트. 머리에 눈 1픽셀(배경색), 가끔 혀 낼름 — **혀만 시그널 레드**
  (빨강 유일 원칙을 마스코트가 계승).
- 몸 색: 밝은 페이지 잉크 `#11110f`, 다크 홈(`.page--home` 존재 시) 종이 `#f1f0ec`.
  등장 시점에 판별.

## 행동 주기 (가끔 나타남)

1. 로드 후 6±3초에 화면 밖에서 등장
2. 뷰포트 가장자리 밴드(바깥 15%)의 웨이포인트를 따라 10~20초 배회
3. 멈춰서 몸을 원형으로 말아 우로보로스 휴식 8~12초
4. 풀고 화면 밖으로 퇴장 → 60~120초 후 다시 1로
- 탭 비활성(IntersectionObserver 아닌 visibilitychange)이면 정지.

## 상호작용 (만지면 동작)

- 캔버스는 `pointer-events: none` — 대신 window pointerdown을 수동 히트테스트.
  뱀 몸 반경 안을 누르면:
  - 배회 중 → 혀 낼름 + 잠깐 빨라짐
  - 휴식(우로보로스) 중 → 깨어나 다시 기어감
- 밑에 깔린 콘텐츠 클릭은 그대로 통과 (가로채지 않는다).

## 접근성·성능

- `prefers-reduced-motion`: 애니메이션 없음 — 우하단에 말린 정적 우로보로스만
  (rAF 0회).
- 화면 밖(퇴장 후 대기)일 때 rAF 정지. `aria-hidden` 캔버스.
- z-index 1100 (챗 fab 1200 아래).

## 하지 않는 것

- 말풍선·사운드·쿠키 기반 기억 — V1은 존재 자체가 전부.
- 콘텐츠 영역 침범 회피 로직 (가장자리 밴드만 다니므로 불필요).

## 검증

- 등장→배회→말림→퇴장 사이클 실브라우저 확인, 히트테스트 클릭 반응 확인,
  reduced-motion 정적 폴백 스크린샷, idle 시 rAF 정지.

## v2 (2026-08-10 오후) — 라운드 · 챗봇 승격

사용자 피드백: "픽셀 말고 더 동글동글하고 귀엽게, 그게 챗봇이 되는거지"

- 픽셀 격자 → **라운드 스티어링**: 머리가 부드럽게 방향을 틀고 몸(원 12개,
  머리 7.5px→꼬리 3px 테이퍼)이 궤적을 따라온다. 말리면 궤적이 감기고
  풀면 저절로 풀린다.
- **마스코트 = 챗 런처**: ASK fab 버튼은 접근성 골격(키보드·스크린리더)만
  남기고 투명화. 그 자리(우하단)에 뱀이 말려 자는 게 챗 버튼의 시각.
  산책 중 만지면 `around:chat-open` 이벤트로 챗이 열리고 놀라서 귀가.
- 행동: 기본 상주(항상 우하단) + 45~90초마다 8~14초 산책 후 귀가.
  잠들면 rAF 0회. reduced-motion은 말린 자세 고정.
